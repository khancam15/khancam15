# Security policy

This repository holds my GitHub profile README. It contains no code, dependencies or deployed services.

## Reporting a vulnerability

If you find a security issue in this repository or in one of my public projects, please report it privately:

- Use GitHub's **Report a vulnerability** button on the repository's **Security** tab, or
- Email contact@khaneilcampbell.com

Please do not open a public issue for security reports. I aim to acknowledge reports within a few days.

## Scope

Each project repository has its own code and, where needed, its own security policy. If a project has a `SECURITY.md`, follow that one.
